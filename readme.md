# White Tab Text

Mod Sine untuk Zen Browser: teks tab jadi **putih** saat tab unloaded atau loaded tapi tidak di-highlight. Saat tab di-highlight (selected), warnanya tetap bawaan tema (hitam).

Nama Space, nama folder, dan tombol New Tab juga putih; icon tab unloaded jadi abu-abu.

Kalau teks masih agak redup, ubah `--wtt-text-opacity` di `chrome.css`.
